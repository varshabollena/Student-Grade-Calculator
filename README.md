# Student Grade Calculator (Python)

## Project Overview

The Student Grade Calculator is a Python program that calculates a student's grade based on marks entered by the user. The program validates the input, determines the grade using conditional statements, and displays encouraging messages based on the result.

## Objectives

* Learn decision making using if-elif-else
* Understand loops for input validation
* Practice creating functions in Python
* Build a simple interactive program

## Setup Instructions

1. Install Python from https://www.python.org/downloads/
2. Download or clone this repository
3. Open terminal in the project folder
4. Run the program:

python grade_calculator.py

## Code Structure

## Grading Logic

A : 90 – 100
B : 80 – 89
C : 70 – 79
D : 60 – 69
F : 0 – 59

## Technical Implementation

The program uses:

* **if-elif-else statements** to determine grades
* **while loop** to validate marks between 0 and 100
* **function** `calculate_grade()` to compute grade and message
* **input()** to get user data
* **print()** to display results
